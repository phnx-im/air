# 本地化术语表（简体中文）

本术语表定义 Air 界面中的关键术语，以保持翻译一致。

模板 `app_en.arb` 决定一条字符串说什么。本术语表决定用哪个词来说。两者冲突时，请指出冲突，不要默默选择其一。

## 变体

本文件覆盖简体中文，词汇遵循中国大陆的用法，因此出现的是“用户”“文件”“设置”“消息”“删除”和“保存”，而不是台湾的对应写法。

简体中文放在基础 locale `app_zh.arb` 中，因为 CLDR 把简体视为“zh”的默认变体。这和 `app_de.arb` 承载德国德语却不叫 `app_de_DE.arb` 是同一种安排。设置为 zh、zh-CN、zh-SG 或 zh-Hans 的设备都会落到本文件。

繁体中文是有标记的变体，有自己的文件 `app_zh_Hant.arb` 和 `GLOSSARY_zh_Hant.md`，遵循台湾用法。两种变体不混用。简体文件不是繁体文件的字形转换，两者的词汇本身就不同，例如“用户”对“使用者”、“设置”对“設定”、“文件”对“檔案”、“消息”对“訊息”。适用于两个变体的决定仍然要分别记录在各自的术语表里，因为每份术语表都是单独阅读的。

## 称呼

Air 在所有字符串中都用“你”称呼用户，不用“您”。这是大陆即时通讯应用的惯例，不因字符串而变。

按钮和标签只写动词，例如“删除”“取消”。完整的指令句和错误提示可以用“请”开头，例如“请重试。”。

## 标点

中文文本使用全角标点：句号“。”、逗号“，”、问号“？”、叹号“！”、冒号“：”、顿号“、”、括号“（）”。引号用“”，引号内再引用时用‘’。

英文以句号、问号、叹号或冒号结尾的字符串，中文以对应的全角标点结尾。英文没有句末标点的标签和标题，中文也不加。校验器把全角标点和对应的半角标点视为等价，所以这一条同时是校验规则。

省略号跟随模板的写法。模板用三个半角点“...”的地方保留“...”，模板用单个“…”的地方保留“…”。

## 空格

中文与拉丁字母、数字或占位符之间加一个半角空格，例如“Air 账号”“最多 5 个用户名”“{displayName} 的消息”。中文与全角标点之间不加空格，占位符后面紧跟全角标点时也不加。

这条规则还有一个技术原因。校验器只在“Air”前后是空格或标点时才把它识别为完整的词，所以“Air账号”会被报告为丢失了产品名。

## 复数

中文的 CLDR 复数规则只有 `other` 一个类别，所以复数消息只用 `=0` 和 `other` 两个分支。不要写 `one` 分支，它永远不会被选中。

量词按对象选择：人用“人”或“位”，设备用“台”，其他对象用“个”。

## 性别

中文没有语法性别，占位符里的名字不需要任何配合。指代对方时用“对方”，需要复数时用“他们”。

## 基本术语

| 术语 | 定义 | 上下文 |
|------|------|--------|
| **Air** | 应用的名称 | 永不翻译。在组合中保留，例如“Air 账号”，中间加空格 |
| **账号** | 用户的 Air 账号 | 写作“Air 账号”，不用“账户” |
| **用户名** | 用户分享给他人以建立联系的唯一标识 | 只用于建立联系 |
| **显示名称** | 在聊天中显示、其他人能看到的名字 | 与用户名不同。这是别人给你发消息时看到的名字 |
| **聊天** | 两人或多人之间的一个会话 | 一对一或群组。不译为“对话”或“会话” |
| **联系人** | 你可以给其发消息的另一位用户 | 写作“Air 联系人” |
| **成员** | 群聊的参与者 | 用于群组语境 |

## 消息术语

| 术语 | 定义 | 上下文 |
|------|------|--------|
| **消息** | 在聊天中发送的文字、图片或文件 | 不用“信息”。“垃圾信息”是唯一的例外，因为它是既定说法 |
| **草稿** | 已输入但尚未发送的消息 | 显示在聊天列表中 |
| **附件** | 随消息发送的文件或图片 | |
| **发消息** | 撰写新消息 | 例如“发消息给 {chatTitle}” |
| **编辑** | 修改已发送的消息 | |
| **回复** | 针对聊天中的某条消息作出回应 | |
| **回应** | 给消息添加表情符号 | 消息上下文菜单操作。例如“{user} 对“…”回应了 {emoji}” |
| **表情符号** | 单个图形字符 | 用于回应选择器 |
| **群组** | 多人参与的聊天 | “群聊”指群组聊天本身 |

## 操作与界面

| 术语 | 定义 | 上下文 |
|------|------|--------|
| **建立联系** | 通过用户名把某人添加为联系人 | 开始与新人聊天的第一步。请求叫“联系请求”。与“关联”不同 |
| **添加** | 把某人加入群组或添加为联系人 | |
| **移除** | 把某人移出群聊 | 对人用“移除”，不用“删除” |
| **删除** | 永久删除内容（消息、文件等） | 对内容用“删除”，对人用“移除” |
| **退出** | 自己离开群组 | 与“移除”不同，后者作用于他人 |
| **屏蔽** | 停止接收某人的消息 | 不用“拉黑”或“阻止” |
| **取消屏蔽** | 撤销屏蔽 | 全部字符串统一用这一个词，包括对话框正文 |
| **静音** | 停止某个聊天的通知 | |
| **取消静音** | 撤销静音 | |
| **关联** | 让另一台设备访问你的账号 | 只用于设备，不用于联系人。不用“连接”或“绑定”。与“建立联系”不同 |
| **取消关联** | 撤销已关联设备的访问权限 | |
| **举报垃圾信息** | 把用户或消息标记为垃圾信息 | 审核功能 |

## 译者须知

- **Air** 永不翻译，它是产品名，在“Air 账号”这类组合中保留，并用空格隔开
- **用户名**与**显示名称**：用户名用来找到人，显示名称用来在聊天中辨认人
- **移除**与**删除**：英文模板选定动词，对人用 remove，对内容用 delete。翻译跟随英文所用的动词，不要自行重新归类
- **建立联系**与**关联**：前者添加联系人，后者添加设备。两个词在所有字符串中保持区分
- **屏蔽**和**取消屏蔽**各自只有一个词，对话框正文也一样
- 英文改写后，请对照当前英文重新翻译，而不是在旧译文上修补
