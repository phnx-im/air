# Glossaire de Localisation (Français)

Ce glossaire fournit les définitions des termes clés utilisés dans l'interface utilisateur d'Air pour assurer une traduction cohérente.

## Variante

Seul le français de France (métropolitain) est utilisé. Les usages propres au Canada, à la Belgique ou à la Suisse ne s'appliquent pas, donc "e-mail" et non "courriel", "discussion" et non "clavardage", et "quatre-vingt-dix" et non "nonante".

Une variante de la langue reçoit ses propres fichiers, un fichier ARB et un glossaire dédiés, au lieu d'être mélangée à la langue de base. Le français canadien serait donc `app_fr_CA.arb` avec `GLOSSARY_fr_CA.md`.

## Registre

Le français utilise le vouvoiement (vous) dans toute l'app. Cela vaut pour tous les strings et ne varie pas d'un string à l'autre.

## Majuscules

L'orthographe française s'applique, pas l'anglaise. Le français met moins de majuscules que l'anglais, donc les majuscules d'un titre anglais ne se reportent pas.

## Termes Fondamentaux de l'App

| Terme | Définition | Contexte |
|-------|------------|----------|
| **Air** | Le nom de l'application | Toujours garder "Air", ne pas traduire |
| **Compte** | Le compte Air d'un utilisateur | Apparaît comme "compte Air" |
| **Nom d'utilisateur** | Un identifiant unique que les utilisateurs peuvent partager pour se connecter | Uniquement utilisé pour les connexions |
| **Nom d'affichage** | Le nom qui apparaît dans les discussions et est visible aux autres utilisateurs | Différent du nom d'utilisateur. C'est ce que les gens voient quand vous leur envoyez des messages |
| **Discussion** | Un fil de discussion entre deux personnes ou plus | Traduit "chat". Ne pas employer "chat" en français |
| **Contact** | Un autre utilisateur à qui vous pouvez envoyer des messages | Apparaît comme "contact Air" |
| **Membre** | Un participant dans une discussion de groupe | Utilisé dans le contexte des discussions de groupe |

| Terme | Définition | Contexte |
|-------|------------|----------|
| **Message** | Un texte, une image ou un fichier envoyé dans une discussion | |

| **Pièce jointe** | Un fichier ou une image envoyé avec un message | |
| **Composer** | Écrire un nouveau message | |
| **Modifier** | Changer un message qui a déjà été envoyé | |
| **Répondre** | Réagir à un message spécifique dans une discussion | |
| **Réagir** | Attacher un emoji à un message | Action du menu contextuel d'un message |
| **Emoji** | Un caractère pictographique | Utilisé dans le sélecteur de réactions |
| **Groupe** | Une discussion avec plusieurs participants | |

## Actions & Interface

| Terme | Définition | Contexte |
|-------|------------|----------|
| **Se connecter** | Ajouter quelqu'un comme contact en utilisant son nom d'utilisateur | Action initiale pour commencer à échanger avec quelqu'un de nouveau. À ne pas confondre avec "Associer" |
| **Ajouter** | Inclure quelqu'un dans un groupe ou l'ajouter aux contacts | |
| **Retirer** | Enlever quelqu'un d'une discussion de groupe | Employer "retirer" quand l'anglais dit "remove" |
| **Supprimer** | Enlever définitivement du contenu (messages, fichiers, etc.) | Employer "supprimer" quand l'anglais dit "delete" |
| **Quitter** | Sortir soi-même d'un groupe | À distinguer de "Retirer", qui concerne quelqu'un d'autre |
| **Bloquer** | Ne plus recevoir de messages de quelqu'un | |
| **Débloquer** | Annuler un blocage | Un seul mot, y compris dans le corps des dialogues |
| **Mettre en sourdine** | Couper les notifications d'une discussion | |
| **Désactiver la sourdine** | Annuler la mise en sourdine | |
| **Associer** | Donner à un autre appareil l'accès au compte | Concerne les appareils, pas les contacts. À ne pas confondre avec "Se connecter" |
| **Dissocier** | Retirer l'accès à un appareil associé | |
| **Signaler comme spam** | Marquer un utilisateur ou un message comme indésirable/spam | Fonction de modération |

## Termes de Fichiers et Données

| Terme | Définition | Contexte |
|-------|------------|----------|
| **Unités d'octets** | Mesures de taille de fichier (o, Ko, Mo, Go, etc.) | Utiliser les unités françaises (octet au lieu de byte) |
| **Taille de la pièce jointe** | La taille du fichier envoyé | |
| **Importer** | Envoyer un fichier ou une image | "Upload" en anglais. Ne pas employer "télécharger", qui dit l'inverse, ni "téléverser". |

## Notes pour les Traducteurs

- **Air** ne doit jamais être traduit, c'est le nom du produit, et il reste tel quel dans "compte Air"
- **Nom d'utilisateur** vs **Nom d'affichage** : le nom d'utilisateur sert à trouver les gens, le nom d'affichage à l'identification dans les discussions
- **Retirer** vs **Supprimer** : le texte anglais choisit le verbe. La traduction suit le verbe anglais au lieu de reclasser l'objet elle-même
- **Se connecter** vs **Associer** : se connecter concerne les contacts, associer concerne les appareils. Les deux mots restent distincts
- **Bloquer** et **Débloquer** ont chacun un seul mot, y compris dans le corps des dialogues
- Considérer le contexte culturel français pour la terminologie de messagerie
- **Octets** : utiliser les unités françaises (o, Ko, Mo, Go) au lieu des unités anglaises (B, KB, MB, GB)
