# Lokalisierungs-Glossar (Deutsch)

Dieses Glossar definiert Schlüsselbegriffe, die in der Benutzeroberfläche von Air verwendet werden, um konsistente Übersetzungen zu gewährleisten.

## Sprachvariante

Es wird ausschließlich bundesdeutsches Hochdeutsch verwendet. Österreichische und schweizerische Besonderheiten gelten nicht, also "Größe" und nicht "Grösse" wie in der Schweiz, und "Januar" und nicht "Jänner" wie in Österreich.

Eine Sprachvariante erhält eigene Dateien, eine eigene ARB-Datei und ein eigenes Glossar, statt in die Basissprache eingemischt zu werden. Schweizer Deutsch wäre also `app_de_CH.arb` mit `GLOSSARY_de_CH.md`.

## Register

Deutsch verwendet durchgehend das informelle "du". Das gilt für alle Strings und wird nicht pro String variiert.

## Groß- und Kleinschreibung

Es gilt die deutsche Rechtschreibung, nicht die englische. Substantive werden großgeschrieben, auch wenn das englische Original sie kleinschreibt.

## Grundbegriffe der App

| Begriff | Definition | Kontext |
|---------|------------|---------|
| **Air** | Der Name der Anwendung | Immer als "Air" beibehalten, nicht übersetzen |
| **Konto** | Das Air-Konto eines Benutzers | Erscheint als "Air-Konto". "Air" bleibt auch im Kompositum erhalten |
| **Benutzername** | Eine eindeutige Kennung, die Benutzer teilen können, um sich zu verbinden | Nur für Verbindungen verwendet |
| **Anzeigename** | Der Name, der in Chats erscheint und für andere Benutzer sichtbar ist | Unterscheidet sich vom Benutzernamen. Das sehen andere beim Nachrichten schreiben |
| **Chat** | Ein Chat-Thread zwischen zwei oder mehr Personen | Zwischen zwei Personen oder in einer Gruppe |
| **Kontakt** | Ein anderer Benutzer, dem man Nachrichten senden kann | Erscheint als "Air-Kontakt" |
| **Mitglied** | Ein Teilnehmer in einem Gruppenchat | Wird im Kontext von Gruppenchats verwendet |

## Aktionen & Benutzeroberfläche

| Begriff | Definition | Kontext |
|---------|------------|---------|
| **Verbinden** | Jemanden mit seinem Benutzernamen als Kontakt hinzufügen | Erste Aktion, um mit jemandem neuen zu chatten. Nicht dasselbe wie "Verknüpfen" |
| **Hinzufügen** | Jemanden in eine Gruppe einbeziehen oder zu Kontakten hinzufügen | |
| **Entfernen** | Jemanden aus einem Gruppenchat nehmen | "Entfernen" für Personen verwenden |
| **Löschen** | Inhalte (Nachrichten, Dateien usw.) dauerhaft entfernen | "Löschen" für Inhalte, "entfernen" für Personen |
| **Verlassen** | Selbst aus einer Gruppe austreten | Im Unterschied zu "Entfernen", das eine andere Person betrifft |
| **Blockieren** | Keine Nachrichten mehr von jemandem erhalten | |
| **Entsperren** | Eine Blockierung zurücknehmen | Immer "entsperren", auch im Dialogtext. Nicht "freigeben" |
| **Stummschalten** | Benachrichtigungen für einen Chat abschalten | |
| **Stummschaltung aufheben** | Eine Stummschaltung zurücknehmen | |
| **Verknüpfen** | Einem weiteren Gerät Zugriff auf das Konto geben | Betrifft Geräte, nicht Kontakte. Nicht dasselbe wie "Verbinden" |
| **Verknüpfung aufheben** | Einem verknüpften Gerät den Zugriff entziehen | |
| **Spam melden** | Einen Benutzer oder eine Nachricht als unerwünscht/Spam markieren | Moderationsfunktion |

## Hinweise für Übersetzer

- **Air** sollte niemals übersetzt werden, es ist der Produktname, und es bleibt in Komposita wie "Air-Konto" erhalten
- **Benutzername** vs **Anzeigename**: Benutzername ist zum Finden von Personen, Anzeigename zur Identifikation in Chats
- **Entfernen** vs **Löschen**: das englische Original wählt das Verb. Übersetzungen folgen dem englischen Verb, statt das Objekt selbst neu einzuordnen
- **Verbinden** vs **Verknüpfen**: Verbinden betrifft Kontakte, Verknüpfen betrifft Geräte. Beide Wörter bleiben getrennt
- **Blockieren** und **Entsperren** haben je genau ein Wort, auch im Dialogtext
- Bei Nachrichten-Terminologie deutschen Konventionen folgen
- Deutsche Kurzlabels sind etwa doppelt so lang wie die englischen, das kann enge Layouts sprengen
