# Глоссарий локализации (русский)

Этот глоссарий задаёт ключевые термины интерфейса Air, чтобы переводы оставались единообразными.

Шаблон `app_en.arb` определяет, что говорит строка. Глоссарий определяет, какими словами это сказать. Если шаблон и глоссарий расходятся, укажите на расхождение, а не выбирайте молча одно из двух.

## Вариант

Используется общепринятый русский литературный язык без региональных особенностей. Буква «ё» пишется везде, где она произносится: «ещё», «удалён», «отчёты».

Вариант языка получает собственные файлы, отдельный ARB-файл и отдельный глоссарий, а не смешивается с базовым языком.

## Обращение

Air обращается к пользователю на «вы» во всех строках. «Вы» пишется со строчной буквы, кроме начала предложения. Обращение не меняется от строки к строке.

Кнопки и пункты меню пишутся инфинитивом: «Удалить», «Отправить», «Отменить» в виде «Отмена». Инструкции и сообщения об ошибках пишутся повелительным наклонением на «вы»: «Попробуйте ещё раз.», «Введите код».

## Регистр букв

Действуют правила русской орфографии, а не английской. Заголовки и кнопки пишутся с заглавной буквы только в первом слове, даже если в английском оригинале заглавные у каждого слова.

## Пунктуация

Кавычки «ёлочки». Английские кавычки "..." и “...” в переводе заменяются на «...». Исключение составляет `deleteAccountScreen_confirmationInputLabel`, где слово 'delete' в прямых апострофах сверяется приложением буквально.

Строка заканчивается тем же знаком, что и оригинал: точкой, вопросительным или восклицательным знаком, двоеточием. Если в оригинале знака нет, в переводе его тоже нет. Многоточие повторяет написание шаблона: три точки «...» там, где в шаблоне три точки, и один символ «…» там, где в шаблоне один символ.

Английская стрелка «→» в пути по меню остаётся стрелкой.

## Множественное число

Русский язык использует категории CLDR `one`, `few`, `many` и `other`. Для целых чисел выбираются `one` (1, 21, 31), `few` (2–4, 22–24) и `many` (0, 5–20, 25). Ветка `other` нужна для дробных чисел, и без неё сообщение не пройдёт проверку. Ветка `=0` формулируется без числа, если так читается лучше.

Если текст одинаков во всех формах, достаточно одной ветки `other`.

## Род и падеж

Имена в плейсхолдерах не склоняются и не несут грамматического рода. Поэтому:

- Глагол прошедшего времени при имени пишется с «(а)»: «{user} добавил(а) {user2}». Это привычная форма в мессенджерах.
- Имя ставится в именительном падеже после поясняющего слова в нужном падеже: «пользователю {displayName}», «от пользователя {displayName}», «в чат {chatTitle}». Не пишите «от {displayName}», где имя должно было бы склоняться.
- Местоимения после «пользователь» согласуются с этим словом в мужском роде: «разблокируете его».

## Стиль

- Придаточное в конце фразы сворачивается в именную группу: «участники ваших групп», а не «участники групп, в которых вы состоите»; «при следующем подключении к сети», а не «когда оно в следующий раз выйдет в сеть». Вместо «который», «кто», «когда» предпочтительны притяжательное, родительный падеж или предложная группа.
- Расплывчатый английский текст переводится конкретно, а не дословно: «something this version cannot provide» это «нужна более новая версия Air», «this content» это «этим». Глагол без дополнения не оставляется: «чтобы начать общение», а не «чтобы начать».
- Необязательное называется необязательным: «фото необязательно», а не «фото указывать не нужно».
- В подписях и коротких строках «группа»: «Новая группа», «создать группу». «Групповой чат» только в развёрнутых предложениях.

## Основные термины

| Термин | Определение | Контекст |
|--------|-------------|----------|
| **Air** | Название приложения | Никогда не переводится и не склоняется. «аккаунт Air», «в Air» |
| **Аккаунт** | Аккаунт пользователя в Air | «аккаунт Air». Не «учётная запись» |
| **Имя пользователя** | Уникальный идентификатор, которым делятся, чтобы с ними связались | Только для установления контакта. Множественное число «имена пользователя» |
| **Отображаемое имя** | Имя, которое видно другим в чатах | Отличается от имени пользователя. Его видят собеседники |
| **Чат** | Переписка двух или более человек | Личный или групповой. Не «беседа» и не «диалог» |
| **Контакт** | Другой пользователь, которому можно писать | «контакт Air» |
| **Участник** | Член группового чата | В контексте групп |
| **Человек, люди** | Английское «person, people» | «Добавить людей», «5 человек» |

## Сообщения

| Термин | Определение | Контекст |
|--------|-------------|----------|
| **Сообщение** | Текст, изображение или файл, отправленные в чат | |
| **Черновик** | Набранное, но не отправленное сообщение | Отображается в списке чатов |
| **Вложение** | Файл или изображение, отправленные с сообщением | |
| **Изменить** | Изменить уже отправленное сообщение | Пометка на сообщении «Изменено» |
| **Ответить** | Ответить на конкретное сообщение | |
| **Реакция** | Эмодзи на сообщении | Кнопка «Реакция», в тексте «отреагировал(а)» |
| **Эмодзи** | Графический символ | Не склоняется |
| **Группа** | Чат с несколькими участниками | «Групповой чат» только в развёрнутых предложениях, см. «Стиль» |

## Действия и интерфейс

| Термин | Определение | Контекст |
|--------|-------------|----------|
| **Запрос на контакт** | Запрос, который отправляют по имени пользователя или из группы | Первый шаг к переписке с новым человеком. Не путать с «привязать» |
| **Добавить** | Включить кого-то в группу или в контакты | |
| **Исключить** | Убрать человека из группового чата | Для людей. Английское «remove» при человеке |
| **Убрать** | Убрать не человека и не содержимое: имя пользователя, реакцию, использованные коды | Английское «remove» во всех остальных случаях |
| **Удалить** | Безвозвратно удалить содержимое: сообщение, чат, контакт, аккаунт | Английское «delete». Не использовать для «remove» |
| **Выйти** | Самому покинуть группу | В отличие от «исключить», которое касается другого человека |
| **Заблокировать** | Перестать получать сообщения от кого-то | |
| **Разблокировать** | Отменить блокировку | Одно слово во всех строках, включая текст диалогов |
| **Отключить звук** | Выключить уведомления чата | Не «заглушить» |
| **Включить звук** | Отменить отключение звука | |
| **Привязать** | Дать другому устройству доступ к аккаунту | Только для устройств. Процесс «привязка» |
| **Отвязать** | Лишить привязанное устройство доступа | |
| **Сообщить о спаме** | Отметить пользователя как рассылающего спам | Модерация |

## Для переводчиков

- **Air** никогда не переводится и не склоняется
- **Имя пользователя** находит людей, **отображаемое имя** их обозначает в чатах
- **Исключить**, **убрать** и **удалить** следуют английскому глаголу. «Remove» при человеке это «исключить», в остальных случаях «убрать». «Delete» всегда «удалить»
- **Запрос на контакт** добавляет человека, **привязать** добавляет устройство. Эти понятия нигде не смешиваются
- Если английский текст изменился, переводите заново по текущему тексту, а не правьте старый перевод
