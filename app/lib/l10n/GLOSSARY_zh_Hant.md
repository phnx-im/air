# 本地化術語表（繁體中文）

本術語表定義 Air 介面中的關鍵術語，以保持翻譯一致。

範本 `app_en.arb` 決定一條字串說什麼。本術語表決定用哪個詞來說。兩者衝突時，請指出衝突，不要默默選擇其一。

## 變體

本檔案涵蓋繁體中文，詞彙遵循台灣的用法，因此出現的是「使用者」「檔案」「設定」「訊息」「刪除」和「儲存」，而不是中國大陸的對應寫法。

簡體中文放在基礎 locale `app_zh.arb` 和 `GLOSSARY_zh.md`，因為 CLDR 把簡體視為「zh」的預設變體。繁體是有標記的變體，所以有自己的檔案。兩種變體不混用。繁體檔案不是簡體檔案的字形轉換，兩者的詞彙本身就不同，例如「使用者」對「用户」、「設定」對「设置」、「檔案」對「文件」、「訊息」對「消息」。適用於兩個變體的決定仍然要分別記錄在各自的術語表裡，因為每份術語表都是單獨閱讀的。

設定為 zh-Hant、zh-Hant-TW、zh-Hant-HK 或 zh-Hant-MO 的裝置會落到本檔案。沒有回報文字系統、只回報地區為 TW、HK 或 MO 的裝置，App 會自行補上 Hant 後同樣落到本檔案。香港和澳門因此看到的是台灣用法。香港在部分詞彙上不同，例如「用戶」「軟件」「網絡」「相片」，若日後需要，會是 `app_zh_Hant_HK.arb` 加 `GLOSSARY_zh_Hant_HK.md` 的獨立變體，而不是混進本檔案。

## 稱呼

Air 在所有字串中都用「你」稱呼使用者，不用「您」。這是台灣即時通訊 App 的慣例，不因字串而變。

按鈕和標籤只寫動詞，例如「刪除」「取消」。完整的指令句和錯誤提示可以用「請」開頭，例如「請再試一次。」。

## 標點

中文文字使用全形標點：句號「。」、逗號「，」、問號「？」、驚嘆號「！」、冒號「：」、頓號「、」、括號「（）」。引號用「」，引號內再引用時用『』。

英文以句號、問號、驚嘆號或冒號結尾的字串，中文以對應的全形標點結尾。英文沒有句末標點的標籤和標題，中文也不加。校驗器把全形標點和對應的半形標點視為等價，所以這一條同時是校驗規則。

刪節號跟隨範本的寫法。範本用三個半形點「...」的地方保留「...」，範本用單個「…」的地方保留「…」。

## 空格

中文與拉丁字母、數字或佔位符之間加一個半形空格，例如「Air 帳號」「最多 5 個使用者名稱」「{displayName} 的訊息」。中文與全形標點之間不加空格，佔位符後面緊接全形標點時也不加。

這條規則還有一個技術原因。校驗器只在「Air」前後是空格或標點時才把它辨識為完整的詞，所以「Air帳號」會被回報為遺失了產品名。

## 複數

中文的 CLDR 複數規則只有 `other` 一個類別，所以複數訊息只用 `=0` 和 `other` 兩個分支。不要寫 `one` 分支，它永遠不會被選中。

量詞按對象選擇：人用「人」或「位」，裝置用「部」，其他對象用「個」。

## 性別

中文沒有語法性別，佔位符裡的名字不需要任何配合。指稱對方時用「對方」，需要複數時用「他們」。

## 基本術語

| 術語 | 定義 | 情境 |
|------|------|------|
| **Air** | App 的名稱 | 永不翻譯。在組合中保留，例如「Air 帳號」，中間加空格 |
| **帳號** | 使用者的 Air 帳號 | 寫作「Air 帳號」，不用「帳戶」 |
| **使用者名稱** | 使用者分享給他人以建立聯繫的唯一識別碼 | 只用於建立聯繫 |
| **顯示名稱** | 在聊天中顯示、其他人能看到的名字 | 與使用者名稱不同。這是別人收到你訊息時看到的名字 |
| **聊天** | 兩人或多人之間的一個對話 | 一對一或群組。不譯為「對話」或「會話」 |
| **聯絡人** | 你可以傳訊息給的另一位使用者 | 寫作「Air 聯絡人」 |
| **成員** | 群組聊天的參與者 | 用於群組情境 |

## 訊息術語

| 術語 | 定義 | 情境 |
|------|------|------|
| **訊息** | 在聊天中傳送的文字、圖片或檔案 | 不用「消息」或「信息」 |
| **草稿** | 已輸入但尚未傳送的訊息 | 顯示在聊天列表中 |
| **附件** | 隨訊息傳送的檔案或圖片 | |
| **傳訊息** | 撰寫新訊息 | 例如「傳訊息給 {chatTitle}」 |
| **編輯** | 修改已傳送的訊息 | |
| **回覆** | 針對聊天中的某則訊息作出回應 | |
| **回應** | 給訊息加上表情符號 | 訊息快捷選單動作。例如「{user} 對「…」回應了 {emoji}」 |
| **表情符號** | 單個圖形字元 | 用於回應選擇器 |
| **群組** | 多人參與的聊天 | 「群組聊天」指群組聊天本身，不用「群聊」 |

## 動作與介面

| 術語 | 定義 | 情境 |
|------|------|------|
| **建立聯繫** | 透過使用者名稱把某人加為聯絡人 | 開始與新對象聊天的第一步。請求叫「聯絡請求」。與「連結」不同 |
| **新增** | 把某人加入群組或加為聯絡人 | 不用「添加」 |
| **移除** | 把某人從群組聊天中移出 | 對人用「移除」，不用「刪除」 |
| **刪除** | 永久刪除內容（訊息、檔案等） | 對內容用「刪除」，對人用「移除」 |
| **退出** | 自己離開群組 | 與「移除」不同，後者作用於他人 |
| **封鎖** | 停止接收某人的訊息 | 不用「屏蔽」或「阻擋」 |
| **解除封鎖** | 撤銷封鎖 | 全部字串統一用這一個詞，包括對話框內文 |
| **靜音** | 停止某個聊天的通知 | |
| **取消靜音** | 撤銷靜音 | |
| **連結** | 讓另一部裝置存取你的帳號 | 只用於裝置，不用於聯絡人。不用「連接」或「綁定」。與「建立聯繫」不同 |
| **取消連結** | 撤銷已連結裝置的存取權 | |
| **檢舉垃圾訊息** | 把使用者或訊息標記為垃圾訊息 | 審核功能。用「檢舉」，不用「舉報」 |

## 譯者須知

- **Air** 永不翻譯，它是產品名，在「Air 帳號」這類組合中保留，並用空格隔開
- **使用者名稱**與**顯示名稱**：使用者名稱用來找到人，顯示名稱用來在聊天中辨認人
- **移除**與**刪除**：英文範本選定動詞，對人用 remove，對內容用 delete。翻譯跟隨英文所用的動詞，不要自行重新歸類
- **建立聯繫**與**連結**：前者新增聯絡人，後者新增裝置。兩個詞在所有字串中保持區分
- **封鎖**和**解除封鎖**各自只有一個詞，對話框內文也一樣
- 英文改寫後，請對照目前的英文重新翻譯，而不是在舊譯文上修補
